# Improving Few-Shot Image Classification with Synthetic Data

Implementation of the ICML 2025 paper:

**"Provably Improving Generalization of Few-Shot Models with Synthetic Data"**

This repository reproduces and adapts the proposed framework for image classification using a combination of limited real images and large-scale synthetic images generated by Stable Diffusion.

The implementation is built on top of:

* CLIP ViT-B/16 Image Encoder
* LoRA (Low-Rank Adaptation)
* K-Means Region Partitioning
* Synthetic Data Regularization Framework proposed in the paper
* Oxford-IIIT Pet Dataset (37 classes)

# Method Overview

The objective is to improve few-shot image classification by leveraging synthetic images while preventing the model from overfitting to artifacts introduced by the image generation process.

The framework combines:

1. Supervised classification learning.
2. Real-Synthetic alignment regularization.
3. Synthetic robustness regularization.
4. Region-wise discrepancy control through feature-space partitioning.

# Feature Space Partitioning

Before model training begins, all training images are embedded using a **frozen CLIP image encoder**.

Let

```text
x → f(x)
```

denote the CLIP feature extractor.

The extracted features are clustered using K-Means:

```text
{f(x)} → K-Means → K regions
```

Each image is assigned a cluster identifier:

```text
cluster_id ∈ {1, 2, ..., K}
```

This clustering step is performed only once before training.

The resulting partitions define local regions used by the discrepancy and robustness losses.

## CLIP Backbone

The image encoder is:

```text
CLIP ViT-B/16
```

Pretrained CLIP weights provide strong visual representations suitable for few-shot learning.

## LoRA Fine-Tuning

Instead of updating all CLIP parameters, LoRA is applied to selected transformer layers.

Advantages:

* Lower GPU memory usage
* Faster training
* Reduced risk of overfitting
* Parameter-efficient adaptation

## Classification Head

A single linear layer maps CLIP embeddings to:

```text
37 classes
```

corresponding to the Oxford-IIIT Pet categories.

# Training Objective

The model is trained using the objective proposed in Equation (7) of the paper.

The total loss is:

L = λF(S,h) + F(G,h) + λ₁Loss_disc − λ₂Loss_rob

where:

* F(S,h): Cross-Entropy on real images.
* F(G,h): Cross-Entropy on synthetic images.
* Loss_disc: Real-Synthetic discrepancy loss.
* Loss_rob: Synthetic robustness loss.

---

# Classification Loss

Two independent classification losses are computed.

## Real Classification Loss

For real images:

```text
F(S,h)
```

Cross-Entropy is computed only using samples from:

```text
Real-Img
```

This term preserves fidelity to the true data distribution.

---

## Synthetic Classification Loss

For synthetic images:

```text
F(G,h)
```

Cross-Entropy is computed using samples from:

```text
Fake-Img
```

This allows the model to benefit from the larger synthetic dataset.

---

# Discrepancy Loss

The discrepancy loss aligns predictions between real and synthetic samples that belong to the same local region.

For each cluster:

```text
S_i = real samples in cluster i

G_i = synthetic samples in cluster i
```

The model computes softmax probabilities:

```text
h(s)

h(g)
```

The discrepancy term minimizes:

```text
|| h(s) - h(g) ||₂
```

for all:

```text
s ∈ S_i
g ∈ G_i
```

Intuition:

* Real images define the target distribution.
* Synthetic images should behave similarly inside the same region.
* Prediction gaps are penalized.

This encourages local consistency between real and generated data.

---

# Robustness Loss

Synthetic images often contain generation artifacts.

To avoid overfitting to such artifacts, the robustness loss enforces consistency among synthetic samples within the same cluster.

For synthetic images:

```text
g1, g2 ∈ G_i
```

the model minimizes:

```text
|| h(g1) - h(g2) ||₂
```

within each cluster.

Intuition:

* Samples describing the same local concept should produce similar predictions.
* Reduces variance caused by synthetic noise.
* Improves generalization to unseen real images.
